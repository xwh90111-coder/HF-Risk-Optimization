# 前端界面使用指南

欢迎使用心力衰竭预测系统！本指南将帮助您了解如何操作本应用的前端界面。

---

## 如何访问应用

为获得最完整的功能体验（包括与后端机器学习模型实时交互），请遵循以下步骤：

1.  在项目根目录下，通过命令行启动后端服务器：
    ```bash
    python app.py
    ```
2.  服务器运行后，在您的网页浏览器中打开以下地址：
    ```
    http://localhost:5000
    ```

---

## 使用步骤详解

应用界面主要分为两部分：数据输入区和结果展示区。操作流程简单直观。

### 第1步：填写临床指标

您需要在表单中输入全部12项患者的临床数据。所有字段均为必填项。

- **数值型输入**: 年龄、肌酸磷酸激酶、射血分数、血小板、血清肌酐、血清钠、随访时间。
- **选择型输入**: 是否贫血、是否患有糖尿病、是否患有高血压、性别、是否吸烟。

请确保您输入的数据格式正确，特别是小数（例如“血清肌酐”支持两位小数）。

### 第2步：选择预测模型

在表单下方，您会看到一个“选择预测模型”的下拉菜单。您可以从中选择一个机器学习模型来进行预测。我们集成了五种模型：

- 逻辑回归 (Logistic Regression)
- 随机森林 (Random Forest)
- 支持向量机 (SVM)
- **梯度提升 (Gradient Boosting) (推荐)**
- **K近邻 (KNN)**

虽然所有模型都可使用，但根据我们的测试分析，“梯度提升”和“随机森林”在准确性上表现最优。

### 第3步：开始预测

填写完所有数据并选择好模型后，点击页面中央的 **“立即预测”** 按钮。

按钮会显示“分析数据中...”，表示您的数据已成功发送到后端进行计算。

### 第4步：解读预测结果

计算完成后，页面会自动滚动到结果区域，并以卡片形式展示预测结果。

- **风险等级卡片**: 这是最直观的结果。
  - **绿色卡片 (低风险)**: 表示模型预测患者发生心力衰竭事件的风险较低。
  - **红色卡片 (高风险)**: 表示模型预测患者有较高的风险，建议关注。

- **风险概率**: 卡片上会显示一个具体的百分比，它代表了模型对于“高风险”这个预测的置信度。

- **主要风险因素**: 如果预测结果为“高风险”，系统会额外展示一个分析模块，列出导致此判断的最主要的数据指标（例如“高龄”、“射血分数偏低”等）。这有助于您理解是哪些因素构成了主要风险。

## 常见问题 (FAQ)

- **问：点击“预测”按钮后页面没有反应或长时间显示加载中怎么办？**
  - **答**：请检查：
    1.  是否所有12个输入框都已填写完毕。
    2.  运行 `python app.py` 的命令行窗口是否依然处于打开和运行状态。
    3.  尝试强制刷新浏览器页面 (快捷键: `Ctrl + Shift + R` 或 `Cmd + Shift + R`) 后再试一次。

- **问：为什么页面看起来很奇怪，没有颜色和样式？**
  - **答**：这通常是因为浏览器加载了旧的缓存文件。请使用上述快捷键进行强制刷新，以确保加载最新的CSS样式文件。
